# Disposable KSP runtime comparison inputs

The supplied KSP 1.12.5, JNSQ 0.10.2, Reborn v1.0.1 and Principia Levy archives and the free dependencies below are installed only in ignored `.work/runtime/ksp`, extracted from the supplied game ZIP. The project never modifies an existing KSP installation. `scripts/Install-DisposableRuntime.ps1` checks path containment and refuses file overwrites. Exact local archive hashes and installed file counts are in `.work/runtime/ksp/ksp-mission-runtime-manifest.json`.

The ModuleManager and ModularFlightIntegrator Jenkins artifact URLs currently return 404. Their ZIPs were fetched from an Internet Archive mirror and accepted only after matching SHA-256 against CKAN's recorded official artifacts: `9109bced44de83aa0cf1540faf09d7f6fea2615145b3ae7c4266dac21f5245d3` and `0134c0950298e8703f27809f918fc57b6f9f7202a9ad988decbf1ac924fdd9e7`, respectively.

The first batch-mode boot loaded ModuleManager and applied 1,084 patches, but Kopernicus reported missing ModularFlightIntegrator and KSPTextureLoader assemblies. They were then installed. The second boot loaded both, but Kopernicus failed to load JNSQAden because the `Parallax` type was absent. These diagnostic boots used Reborn's default Standard scale and produced no valid body snapshot. The disposable config was then set to `SystemScale = Real` with `scripts/Configure-DisposableRebornReal.ps1`; it keeps `RealTime = True`. The modified config's SHA-256 is `5c56f93d94b6fe6bd494012829a346edcd5d4ef91c2ba5d0956d3333cf8c8e6a`.

The third muted batch-mode boot selected Real scale and applied 1,172 ModuleManager patches. Kopernicus and Parallax reached the main-menu startup path, but `KSP.log` then repeated `NullReferenceException` in `Parallax.Scaled_System.ScaledMainMenu`. The game used Unity's Null Device in batch mode, so this is a headless graphics-path failure, not evidence of a successful rendered game load or a verified planetary state. No Principia flight snapshot was captured. The disposable process was stopped after collecting the log. `scripts/Mute-DisposableKsp.ps1` set master, ship, ambience, music, UI and voice volume to zero in that copy; no existing KSP installation was changed.

The [Reborn maintainer's README](https://github.com/rbeap/JNSQ-Reborn) additionally requires VertexMitchellNetravaliHeightMap, Parallax Continued, EVE Volumetrics V5 and Deferred Rendering, and recommends BurstPQS and scenery. The user initially chose to continue without V5, then supplied the preview archive described below. The supplied Principia Levy adapter identifies version `2026.09.11.256` in the game log. The runtime exporter still needs a loaded flight and Principia state before any `runtime_verified` claim.

On 22 September the user supplied a Drive ZIP named `RaymarchedVolumetricsEarlyAccess23_08_26.zip` (836,022,162 bytes, SHA-256 `c7ec249c6f0e6783e3545a7bac16f0c8fcb18825dd680aa025cafad9425ecd30`). Its internal EVE version file says 3.2.2 for KSP 1.12.5, and its changelog begins 23 August 2026. The preview archive includes EnvironmentalVisualEnhancements, Scatterer, stock config packs and Blackrack_TUFX. Its readme instructs a GameData merge into a clean installation. The archive is all rights reserved and stays under ignored `.work/inputs`; it is not redistributed by this repository. The release name does not itself prove equivalence to Reborn's specifically named `EVE Volumetrics V5` dependency.

The supplied preview installed 165 files into the disposable copy. A muted Direct3D 11 load applied 1,291 ModuleManager patches, logged EVE assembly 3.2.2 and Scatterer 0.0908, found JNSQ named bodies, and loaded the x64 Principia native DLL. Parallax then reported missing `Parallax_StockTerrainTextures/Kerbin/PluginData/low00.dds` and related textures. The official [Parallax Continued 1.0.4 release](https://github.com/Gameslinx/Parallax-Continued/releases/tag/1.0.4) says its texture archives are separate; the needed terrain texture archive was absent from that load. KSP was stopped after collecting the log. No flight snapshot or visual runtime acceptance was obtained.

The separate official Parallax 1.0.3 asset archives were subsequently downloaded, path-checked and installed in that same disposable copy: terrain ZIP SHA-256 `93a588a668c4f5968d70f997371a09d8f48e0740e5144af61bcdaf450dcefc6a` (1,990,694,985 bytes), planet ZIP `4c2d78607f34681c80db496338a85da04a5f9425e74aecd1b87c70f1eae194ba` (245,859,412 bytes), and scatter ZIP `f1eed047140c7c24695315360df1da9a16ea7b3c26e1c8794feff15c64f0c6c0` (1,171,119,601 bytes). Each ZIP has no traversal paths and remains ignored under `.work/inputs`. This resolves the missing asset files on disk, but there has been no subsequent game launch: native project windows were opening on the user's main Windows desktop, so visual runtime checking is paused until they can be placed on the requested desktop. No runtime snapshot or Principia comparison was produced.

The user approved these free game mods for the disposable copy. That approval did not include purchasing a paid EVE V5 membership.
