# M4 headless bounded-shooting worker validation

The failure cases in `M4-WORKER-SHOOTING-CONTRACT.md` were specified before implementation on 23 September 2026, and worker/core tests were added before the production code. The new protocol-version-1 command accepts the existing runtime-only fixed-route trial plus bounded shooting limits. It reads exact source bytes with SHA-256, uses their frame, epoch, confidence and atmosphere boundaries, and returns the final physical trial with signed coarse diagnostics. Only an unchanged strict evaluator result can produce `checkpointed_accepted`; other completed searches carry the coarse diagnostic label.

The core now checks cancellation between probe propagations and before/after strict repropagation. The worker emits source-linked, monotonic, throttled probe progress and exactly one terminal event. The one-time planetary integration and any individual spacecraft propagation remain noninterruptible and are disclosed in `started`. A Sol High review found that unsafe thrown probes initially did not consume the evaluation cap. The fix charges every attempted probe before propagation and reports progress for success or throw. A focused unsafe-difference test exhausts a two-probe cap without acceptance. The reviewer found no remaining P1/P2 issue after the fix.

The runtime-shaped worker test repairs a nearby manufactured impulse seed, then replays its emitted `final_trial` through `evaluate_route` against the same exact-byte snapshot. Strict burns, checkpoints, disagreement and charged delta-v match. Tests also cover pre-work, between-probe and post-strict cancellation; missing Venus and strict disagreement as diagnostic non-success; malformed/extra fields, seed and budget caps, wrong frame/epoch, stale hash, same-length source rewrite, caller atmosphere override and an unsafe byte-backed Venus atmosphere. Progress and the terminal payload are bounded by the protocol caps.

Focused worker and evaluator CTest passed 2/2 on MSYS2 UCRT and 2/2 on MSVC Debug. Full local MSYS2 build, including the worker and desktop targets, succeeded; CTest passed 14/14. [GitHub Actions run 35827275407](https://github.com/sixnationn/ksp-mission-analysis/actions/runs/35827275407) passed all six Ubuntu 24.04 and Windows 2022 jobs for source commit `a9925b0`.

This validates a runtime-shaped manufactured fixture and headless protocol behavior. It does not establish a feasible real JNSQ Reborn route, an installed KSP/Principia comparison, route-seed evidence, or continuously certified Mars-stay clearance. WorkerClient, reports and GTK do not yet consume the new shooting event schema.
