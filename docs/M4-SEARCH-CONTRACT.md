# M4 search contract and first numerical slice

Specified before implementation. M4 consumes an ephemeris and spacecraft propagator tied to the same complete snapshot, frame, epoch, force model and coverage. The M1 raw JNSQ catalog cannot drive a search. A candidate is a dated trajectory with source identity, settings, residuals and burns; a screen pass is not a feasible refined mission.

## Screening

The first independent slice is a deterministic zero-revolution Lambert solver for two central-body-relative position vectors in the same right-handed inertial basis, positive central gravitational parameter and positive time of flight. It returns central-body-relative endpoint velocities. A caller starting from barycentric states must subtract the central body's position at each endpoint and add its velocity to each returned endpoint velocity. The branch (short/long path and direction of angular momentum) is explicit. It rejects nonfinite or zero vectors, nonpositive time or parameter, coincident endpoints, collinear and near-antipodal geometry when the chosen formulation is singular, an unbracketed solution, and a residual above declared absolute position and velocity bounds. It never returns a plausible-looking state after a failed solve. Compare with independently propagated circular and asymmetric conics over short and long branches; report actual endpoint residuals and time convergence.

An unpowered flyby seed uses planet-relative incoming and outgoing asymptotic velocities. It requires positive finite speeds, agreement of speed magnitudes within a named tolerance, a positive turn, a finite periapsis no larger than an explicit encounter-distance limit, and a turn angle no larger than `2 asin(1/(1 + r_p v_inf^2 / mu_planet))` at or above the body's radius plus atmosphere and safety margin. It records required turn, maximum turn, minimum periapsis, speed mismatch and their margins. A powered assist has a separate explicit burn; an unpowered seed never hides a speed change. Reject an unknown atmosphere rather than silently using zero. A zero-turn coast is not an assist.

The screen takes explicit launch and flight-time ranges, step sizes, stable seed, candidate limit and ephemeris identity. It must reject coverage gaps and invalid grids, produce repeatable ordered candidates, and say `no feasible screened seed` when none pass. Search objectives and constraints remain distinct. The requested route is home departure, Mars capture/rendezvous, fixed 5,184,000 SI-second parking stay, Mars departure, Venus unpowered flyby, home return. It is not four flybys. The exact body mapping and mission limits must be present in a mission file before running the requested scenario.

## Refinement and acceptance

The second slice refines selected seeds with the M3 n-body propagator and explicit impulses. It must use a separate tighter propagation for final constraint evaluation, report each burn and residual, reject unsafe entry or unresolved event isolation, and retain the source snapshot hash. Report diversity and a feasible set; never call the best sampled candidate a global optimum. A known synthetic feasible transfer, an impossible geometry, a too-low flyby, speed mismatch, repeatability, and independent tighter repropagation are required before M4 acceptance. The first Lambert/flyby slice may pass its own tests while M4 as a whole remains open.

The current `refine_terminal_position` primitive targets only a position at the supplied end UT in the snapshot's inertial frame. It returns `terminal_position_targeted_only`; it does not verify arrival velocity, capture, a dated body encounter, a gravity assist, or the whole route. It rejects an ephemeris whose declared fit position budget plus velocity budget over the leg exceeds 10% of the smaller terminal and disagreement tolerances. It reconstructs the planetary ephemeris with half the step, compares planetary state at nine dates, and uses that tighter ephemeris for the final spacecraft repropagation. This is a step-convergence and local fit gate, not an independent planetary force-model comparison or a Principia match. The current synthetic RK4 check is a narrow terminal-position benchmark, so M4 remains open.
