# Runtime snapshot worker slice

Specified before implementation. Extend the version 1 JSON-line worker with `source.mode = "runtime_snapshot"`, `source.path` and `source.expected_snapshot_hash` (64 lowercase hex characters). The worker reads at most 16 MiB of exact local file bytes once, verifies that the same opened file has no unread suffix, checks the hash and the Principia runtime schema through the shared C++ runtime reader, then derives the source identity, body states, atmosphere boundaries and capture UT from that immutable in-memory load. It never silently falls back to the synthetic fixture or treats a raw-config import as an analysis-ready state. The existing `synthetic_fixture` mode and its labels remain explicit.

For runtime mode, require a bounded `ephemeris` object with finite `end_ut_s`, positive `step_s`, positive fit budgets and at most 100,000 integration steps from the snapshot capture UT. The dated grid must name body IDs from the loaded snapshot, use its right-handed inertial frame and lie entirely in ephemeris coverage. Build one independent Newtonian point-mass ephemeris and screen one-leg Lambert seeds; every event after successful load carries the exact snapshot hash and `runtime_observed_uncompared` confidence. `started` names the force model, units, frame, coverage and checkpoint-only cancellation. `candidate` and final ranked rows remain `screened_seed`; neither is a verified runtime route or Principia-equivalent solution. This slice does not accept a provisional M1 catalog or launch the GTK window.

Observe rejection before implementation for unreadable/oversized or concurrently grown file, bad hash, invalid JSON or source provenance, missing state/atmosphere, unknown body IDs, unsupported source mode, nonfinite/negative integration settings, too many steps, and grid dates outside coverage. A valid runtime-shaped synthetic fixture must produce matching hash/confidence in `started`, progress and final rows. Candidate IDs must incorporate source identity and the role/branch/grid request so distinct searches cannot collide merely because they share a snapshot and grid index. Cancellation must retain the source identity and any accepted ranked seeds, and malformed control lines must not crash the worker. File content is read once so later path changes cannot alter the running search. The numerical result is still a screen; full route search and installed-game comparison are separate acceptance gates.
