# M6 route-screening checkpoint

22 September 2026. This is an implemented, bounded **patched-conic screening slice**, not M6 acceptance or a validated JNSQ mission. It joins home → Mars-role, a 5,184,000 SI-second parking-orbit stay, Mars-role → Venus-role, an unpowered Venus-role flyby and Venus-role → home. It reports home injection, Mars capture, Mars departure and home return capture separately, plus departure and return C3. Entry return, surface stay and unpriced powered flyby are rejected or unsupported.

The route contract was written before the implementation. The first tests failed on the missing source. A Sol High review then found that fabricated legs could pass; fixes re-solve each leg against dated ephemeris states and canonicalize retained Lambert velocities, residuals and derived v∞ values. The review also closed double-counted stay tolerance, mixed Venus encounter epochs, nonpositive flight time and retention of up to one million full route objects. A second-pass test reproduced a 0.0005 m/s stored-velocity perturbation before canonicalization; the final route now uses the re-solved values for burns and flyby geometry.

Windows MSYS2 UCRT64 Release: the full CMake build and all **8/8 CTest targets** pass. The direct route target reports **38 checks**, including wrong roles/source/epochs, fabricated velocities, stay and flyby mismatch, invalid atmosphere/altitude, unsupported entry, no route, deterministic ordering and 1,000-combination bounded top-K retention. Its Lambert-derived synthetic fixture gives an optimistic four-burn total of **58,181.2460942699 m/s**, departure and return C3 each **275,785,392.730384 m²/s²**, and a screened Venus periapsis of **117,843.151412753 m**. Those numbers are deliberately synthetic and are not a claim about the installed JNSQ system. The fixture uses a manually static ephemeris table.

Still open for M6: a complete route search and n-body refinement of all legs and assists, constraint margins under that propagation, independent tighter repropagation, a report with exact runtime snapshot identity, a loaded JNSQ Reborn Real flight state, installed KSP/Principia comparison, and a feasible or infeasible conclusion for the requested mission. The GTK window does not yet connect to this assembler. Native project windows remain stopped while virtual-desktop placement is unresolved.
