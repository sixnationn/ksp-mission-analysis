# Bounded three-leg route search contract

Specified before implementation. Build an internal C++ search that combines existing M4 one-cell Lambert screening with the reviewed M6 route assembler. This is an exhaustive **bounded grid screen**, not a global optimizer or a claim of mission feasibility. It accepts one analysis-ready snapshot, one matching independent Newtonian ephemeris, exact home/Mars-role/Venus-role/central IDs, a launch grid, three independent flight-time grids, the 5,184,000 SI-second parking stay, and the existing parking/flyby constraints. It does not read provisional M1 configs or select body roles by array position.

For every launch/first-flight cell, screen home → Mars-role. For each accepted seed, set Mars departure UT to its arrival UT plus exactly 5,184,000 seconds, screen the second flight grid, set Venus departure UT to the accepted second arrival UT, then screen the return flight grid. Pass three singleton seeds to `assemble_routes` so its dated ephemeris, Lambert, flyby, burn and source checks remain authoritative. Retain only the best K screened routes during enumeration, rank deterministically by optimistic four-burn delta-v and stable tie keys, and give each retained route an identity containing source, roles, branch/direction and exact leg dates. Do not use a per-leg top-K that can discard a route before joining.

Preflight the source/frame/force model, finite positive step sizes, integer grid counts, ephemeris coverage for the worst-case route, body roles and atmosphere/parking constraints. Bound prospective one-cell evaluations with overflow-safe arithmetic to at most a declared `max_cells` (hard ceiling 100,000) before entering any loop. The duration cap and route constraint checks remain active. Report sampled and rejected cells, considered route combinations, retained routes, source hash/confidence, and `patched_conic_screened_route` only. A cancellation callback is checked between cells and returns explicit partial/cancelled status; a progress callback is monotonic and never runs inside an uninterruptible Lambert solve.

Observe failures before implementation for zero or noninteger grid step, overflow/excess cells, insufficient ephemeris coverage, wrong source/frame/role, unknown atmosphere, invalid stay/altitude, impossible flyby and no route. A positive controlled synthetic fixture must recover the same screened route and four burn components as the direct assembler, with repeated-input equality; a two-date fixture must retain distinct IDs and deterministic top-K. Cancellation must keep only already accepted routes and never report `complete`. Full n-body refinement, independent tighter repropagation, real JNSQ flight state and installed Principia comparison remain separate acceptance gates.
