# M2 mission-worker cache validation

The observable cases in `M2-WORKER-CACHE-CONTRACT.md` were specified before implementation on 23 September 2026. The worker now accepts an optional top-level `ephemeris_cache: {"path": "..."}` on `start_mission`. It validates the exact source, frame, epoch, body roles, atmosphere values, work limits and route preflight before cache use. A fresh path integrates and publishes an immutable file before search; an existing regular path loads only when the full snapshot/settings/fit identity matches. A corrupt, stale or nonregular cache fails without recomputing or emitting a route. The single-leg `start` command and fixed-route evaluator do not use this cache.

The worker test failed on missing `created` status before code. It then passed on MSYS2 UCRT and MSVC Debug. The tests compare no-cache, created-cache and cache-hit ephemeris metadata and ranked routes; verify the hit leaves file bytes unchanged; and exercise malformed request shape, stale step, corrupt file, source-hash rejection before cache use, missing parent, existing directory and pre-work cancellation. The test uses a unique disposable directory. A Sol High read-only review found no remaining P1/P2 issue after nonregular entry classification was corrected.

Local MSYS2 UCRT full CTest passed 14/14, including desktop compilation. The focused worker test passed 1/1 on MSYS2 UCRT and 1/1 on MSVC Debug. [CI run 35814176339](https://github.com/sixnationn/ksp-mission-analysis/actions/runs/35814176339) passed all six Ubuntu 24.04 and Windows 2022 jobs at source commit `b51bc1f`, including both C++ CTest matrices and desktop build checks.

The result is still `patched_conic_screened_route` using an `independent_newtonian_nbody` ephemeris. A cache hit does not establish installed KSP/Principia agreement or a feasible/optimal n-body mission. The cache loader detects damage and length changes but does not lock out a same-size concurrent in-place rewrite after reading. The 128 MiB file cap remains. Next numerical work is a bounded multiple-shooting search that supplies physical parking states and fixed impulses to the existing full-route evaluator; runtime exporter/installed comparison and UI rendering remain separate gaps.
