# Runtime worker checkpoint

22 September 2026. The version 1 JSON-line worker now accepts a `runtime_snapshot` source path and caller-supplied lowercase SHA-256. It reads up to 16 MiB once, checks for observed file-size changes on the same open handle, verifies the exact captured bytes and runtime schema through the C++ reader, and runs a bounded independent Newtonian ephemeris and one-leg Lambert screen. The existing synthetic worker mode remains explicit. Runtime refinement is rejected in this slice.

Tests were written before implementation. A Sol High provenance review found a file-growth race and candidate-ID collisions between distinct searches; a deterministic append-after-read test first reproduced the file issue. Candidate IDs now hash the snapshot, role IDs, branch, direction, grid and ephemeris settings before adding cell indexes. Windows MSYS2 UCRT64 Release builds and the full **8/8 CTest suite** passes; the direct worker target reports **78 checks**. A runtime-shaped synthetic file produces the same exact hash and `runtime_observed_uncompared` confidence in started, progress, candidate and final ranked events. Tests also reject unreadable and oversized files, bad hashes, malformed JSON, invalid Principia provenance, missing state or atmosphere, unknown roles, invalid integration settings, excess steps and out-of-coverage dates. Cancellation retains the loaded source identity and accepted ranked seeds.

A separate headless CLI smoke emitted started, progress and complete events for a runtime-shaped fixture and correctly reported `no_screened_seed` for its geometry. The test file is hand-built, not an installed-game export. Changes to the file after a successful read do not affect the in-memory search. A same-length concurrent rewrite or a change after the final file-size check is not detected, but the search still uses only the bytes whose SHA-256 was validated.

[GitHub Actions run 35793104139](https://github.com/sixnationn/ksp-mission-analysis/actions/runs/35793104139) passed all six native Ubuntu 24.04 and Windows 2022 jobs with this worker mode, including GTK/worker builds and the CTest suite. This confirms cross-platform compile and tests, not a rendered UI or game comparison.

Still open: testing a real exporter-produced flight snapshot, stdin cancellation under a broad workload, multiple-leg runtime search and route refinement, GTK integration, and installed KSP/Principia comparison. These candidates remain `screened_seed` with independent Newtonian provenance, not runtime-verified solutions.
