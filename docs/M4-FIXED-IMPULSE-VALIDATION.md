# Fixed-impulse n-body checkpoint

Every recorded Venus closest approach across the propagated route is checked against the source-bound atmosphere and requested Venus safety margin, including events outside the screened encounter window. A two-approach regression rejects a later unsafe event.

The route evaluator propagates one explicit launch parking state with four specified impulses at launch, Mars capture, Mars departure and home return. It checks body-relative parking states at the named epochs, an actual unpowered Venus closest approach within a bounded time/radius window, source/frame/epoch identity, SI units and separate coarse/strict position, velocity and event-time disagreement limits. The strict run reintegrates the massive bodies with a smaller step and reruns the same fixed impulses with tighter spacecraft settings. The runtime entrypoint parses exact snapshot bytes and SHA-256 through `RuntimeReader`; atmosphere boundaries come from those bytes. A separate synthetic entrypoint rejects claimed runtime state.

Tests observed rejection failures before implementation and before provenance hardening. The manufactured four-body fixture exercises four burn records and a real Venus closest-approach root; its minimum distance is about 999,964 m. It measures a maximum 2.00988 m coarse/strict relative-position difference, 2.4459e-6 m/s relative-velocity difference and 0.00175197 s Venus event-time difference. Negative tests include stale/altered source bytes, false runtime confidence, changed byte-backed Venus atmosphere, missing body/atmosphere, wrong frame/epoch, malformed dates, unsafe parking/flyby, extra burns, fit-budget overrun, two Venus approaches and separate strict-disagreement failures. The focused MSYS2 UCRT64 executable passed **37 checks**; Visual Studio focused CTest passed **1/1** before the final two-approach regression. The full MSYS2 UCRT64 suite passed **12/12** after that regression. Ubuntu and Windows CI for this new target is pending.

The result label is `independent_nbody_fixed_impulse_checkpointed_only`. The supplied Lambert seed is treated as an untrusted date/role seed, and the evaluator does not certify its original ephemeris or Lambert evidence. Mars parking is checked after capture and before departure, but the entire 5,184,000-second stay is not continuously bounded; `mars_stay_continuously_verified=false`. The tests establish internal numerical consistency on synthetic data, not optimization, a real JNSQ Reborn capture, Principia agreement, or a playable flight plan. Continuous parking validation, bounded multiple shooting, independent trajectory comparison and installed-game checks remain open.
