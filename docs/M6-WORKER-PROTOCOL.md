# M6 bounded route worker protocol

Contract before implementation. Extend the version 1 JSON-lines worker with a distinct `start_mission` command. Its source must be the same exact-byte verified runtime snapshot supported by the existing worker, or an explicitly named synthetic four-body fixture for controlled checks. The request supplies an independent Newtonian ephemeris horizon, exact central/home/Mars-role/Venus-role body IDs, a launch grid, three positive SI-second flight grids, the 5,184,000-second parking stay, parking/capture altitudes, and an unpowered flyby clearance. Atmosphere boundaries for every role come from the runtime snapshot; the request cannot override them. The first release supports parking-orbit return capture only.

Validate the source hash, frame, state epoch, body roles, coverage, fit settings, work cap and every grid before emitting `started`. The work cap is the prospective count of first-leg, second-leg and third-leg Lambert cells, at most 100,000. The worker emits versioned `started`, monotonic `progress`, optional screened-route updates, and exactly one terminal `complete`, `cancelled` or `error`, each with request ID and source hash/confidence once loaded. Route updates include the distinct route ID, all three dated legs, the four separately charged parking burns, total optimistic delta-v, flyby clearance and explicit `patched_conic_screened_route` label. Terminal results are deterministically ranked and capped; an update is not itself a final result. Cancellation is checked between cells, and a cancelled terminal carries only accepted partial routes.

Before implementing, observe failures for missing or conflicting atmosphere data, wrong hash/frame/role, insufficient coverage, noninteger or excessive grids, impossible flyby and no route, malformed event metadata, cancellation and child exit. A synthetic fixture must recover the direct `MissionSearch` result and preserve source identity. A real runtime snapshot run is only an independent-model screen until its initial state and trajectory have been compared with the installed KSP and Principia. Full multi-leg n-body refinement and independent tighter repropagation remain later gates.
