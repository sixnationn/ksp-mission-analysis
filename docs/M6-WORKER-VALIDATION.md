# M6 route worker checkpoint

The version 1 JSON-lines worker now accepts `start_mission` for an exact-byte runtime snapshot or an explicitly synthetic four-body fixture. It validates source hash, inertial frame, epoch, body roles, atmosphere provenance, ephemeris coverage, three flight grids, the fixed 5,184,000-second parking stay, and a 100,000-cell prospective work cap before `started`. The route result is labeled `patched_conic_screened_route`; no Principia-equivalence or full-route n-body feasibility is claimed.

Failure cases were exercised before implementation. The worker tests cover wrong hash/frame/role, missing or conflicting atmosphere data, invalid grids and coverage, capped work/route counts, no route, cancellation, and the synthetic result matched to the direct mission search. The client tests reject malformed route events, wrong source identity, inconsistent dates and burn totals, and exercise a real worker subprocess. The headless Windows MSYS2 UCRT64 checks passed 131 worker checks, 59 client checks, 21 report checks, and 11/11 CTest targets on 22 September 2026. Ubuntu native CI and GTK rendered inspection remain pending for this slice.

The runtime-shaped test snapshot checks exact bytes, frame and atmosphere handoff. It is test data, not an observation from an installed JNSQ/Principia game. The worker returns optimistic four-burn ranking and flyby clearance, with integration and each Lambert solve as non-interruptible stages. Full multi-leg n-body refinement, tighter independent propagation, real-game comparison, and playable flight export remain open.
